# YoungLA Landing Page Clone (HubSpot CMS)

A custom **HubSpot CMS** theme inspired by the YoungLA landing page. This project demonstrates building reusable CMS components, dynamic content with HubDB, and serverless functionality within the HubSpot ecosystem.

## 🌐 Live Demo

**https://47574277.hs-sites.com/youngla-clone**

## Features

- Custom HubSpot CMS theme
- Reusable React-based HubSpot modules
- Dynamic landing page template
- CSS Modules for maintainable, component-scoped styling
- HubDB integration for dynamic image management
- Serverless functions to retrieve and display images
- Local development and deployment using the HubSpot CLI

## Tech Stack

- HubSpot CMS
- React
- HubL
- CSS Modules
- HubDB
- HubSpot CLI
- HubSpot Serverless Functions
